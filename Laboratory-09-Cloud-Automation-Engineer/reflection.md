# Reflection

Automation is important when managing hundreds of cloud servers because it saves time and reduces manual work. Instead of doing the same tasks repeatedly, administrators can use scripts to perform tasks automatically. This also helps reduce human errors.

However, automation can be dangerous if a script contains mistakes. For example, if a destructive command runs on 1,000 servers, it could delete important files or damage systems. That is why scripts should be checked and tested before using them.

Writing a Bash script is different from creating a Docker Compose YAML file in Mission 6. Bash scripts use commands to perform tasks automatically, while Docker Compose YAML is used to configure and run containers. Both are useful for managing cloud environments.

From Laboratory 1 to Laboratory 9, my understanding of cloud computing has improved. I learned about cloud infrastructure, databases, containers, deployment, operations, security, and automation. These activities helped me understand how cloud systems work and how to manage them properly. I also learned that keeping data safe and making systems work efficiently are important parts of cloud computing.

The role I enjoyed the most was the Cloud Automation Engineer because I learned how to create a script that backs up files automatically. I found it useful because the computer can perform the task without needing someone to run the command every time. This mission taught me that automation makes work easier, but scripts must still be tested carefully. Overall, the laboratory activities helped me gain more knowledge about cloud computing and the different responsibilities involved in managing cloud systems.
