# Cloud Platform Recommendation Challenge 

## Client A – Startup Company

### Recommended Cloud Platform: AWS

AWS is recommended because the startup has a limited budget but expects to grow in the future. The company can start with cloud resources based on its current needs and increase them as the application grows. AWS provides services that can support computing, storage, and databases.

### Services

- Amazon EC2
- Amazon S3
- Amazon RDS

---

## Client B – University

### Recommended Cloud Platform: Microsoft Azure

Microsoft Azure is recommended because the university already uses Windows Server, Microsoft 365, and Active Directory. Azure works well with existing Microsoft technologies and can make migration to the cloud easier. It also provides services for computing, storage, and identity management.

### Services

- Azure Virtual Machines
- Microsoft Entra ID
- Azure Blob Storage

---

## Client C – AI Research Company

### Recommended Cloud Platform: Google Cloud Platform

Google Cloud Platform is recommended because the company develops AI and machine learning applications. GCP provides services that support AI workloads and large amounts of data. It also offers cloud computing resources for demanding applications.

### Services

- Vertex AI
- Compute Engine
- Google Kubernetes Engine

---

## Client D – Global E-Commerce Company

### Recommended Cloud Platform: AWS

AWS is recommended because the company serves customers around the world and needs reliable infrastructure. AWS provides scalable services that can handle changing workloads and high traffic. Its cloud infrastructure can also support applications deployed in different locations.

### Services

- Amazon EC2
- Elastic Load Balancing
- Amazon CloudFront

## Multi-Cloud Decision Matrix

| Business Requirement | Recommended Platform | Justification |
|---|---|---|
| Startup Company | AWS | Provides flexible cloud resources that can support future growth |
| Enterprise Organization | AWS | Offers many cloud services for different business needs |
| Microsoft Environment | Azure | Integrates well with Microsoft products and technologies |
| AI / Machine Learning | GCP | Provides specialized services for AI and machine learning |
| Kubernetes Deployment | GCP | Provides strong Kubernetes support |
| Global Web Application | AWS | Provides scalable services and global infrastructure |
