# Mission Reflection

The cloud platform that impressed me the most was Amazon Web Services (AWS). I was impressed because it offers many different cloud services that can be used for computing, storage, networking, and other business needs. I also learned that AWS can support both small projects and large organizations.

AWS, Microsoft Azure, and Google Cloud Platform all provide important cloud services such as compute, storage, networking, and identity management. Although the names of their services are different, they offer similar functions and help organizations build and manage cloud applications. All three platforms can also provide scalable resources based on business requirements.

Business requirements are important when choosing a cloud platform because different organizations have different needs. For example, an organization that uses Microsoft products may choose Azure, while a company focused on AI and machine learning may prefer Google Cloud. The selected cloud platform should match the organization's technology, budget, and business goals.

I learned how to compare different cloud platforms and recommend a suitable platform based on the needs of a client. I also learned that choosing a cloud provider is not only about selecting the most popular platform. It is important to understand the client's requirements before making a recommendation.

My GitHub portfolio improved because I added more organized cloud computing documentation and research. I was able to create Markdown files for cloud platform research, comparisons, client recommendations, and Linux server investigation. This activity also helped me improve my skills in using GitHub and writing technical documentation.
