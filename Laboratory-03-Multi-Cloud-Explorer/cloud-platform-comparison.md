# Google Cloud Platform (GCP)

## Brief Overview

Google Cloud Platform is a cloud computing platform provided by Google. It offers services for computing, storage, networking, artificial intelligence, and application development.

## Global Infrastructure

Google Cloud has infrastructure located in different regions around the world. This allows organizations to deploy cloud resources closer to their users.


## Cloud Management Console

Google Cloud provides the Google Cloud Console for creating and managing cloud resources.


## Four Core Services

| Service | Description |
|---|---|
| Compute Engine | Provides virtual machines for workloads |
| Cloud Storage | Provides cloud storage for files and data |
| Virtual Private Cloud | Provides networking for cloud resources |
| Cloud IAM | Manages access and permissions |

## Three Advantages

- Provides strong support for AI and machine learning.
- Offers services for data and analytics.
- Supports containers and Kubernetes.

## Typical Enterprise Use Cases

GCP can be used for AI applications, machine learning, data analytics, and containerized applications.
