# Laboratory 01 – Welcome to the Cloud
---

## Mission Overview
This activity introduced me to Linux and basic tasks used in cloud work. I used KillerCoda terminal to run commands and GitHub to store and show my portfolio work.

---

## Objectives
- Access Linux environment through KillerCoda
- Learn basic navigation and system commands
- Check OS, memory, and storage details
- Create and organize folders and files properly
- Set up a repository on GitHub
- Use Markdown style for writing documentation

---

## Activities Performed
- Opened and used KillerCoda Linux terminal
- Created new user account and gave it sudo/admin access
- Ran commands to check identity and collect system information
- Made directories and files from scratch following the structure
- Copied finished documents into correct portfolio folder
- Prepared all files ready to upload to GitHub

---

## Linux Commands Used
adduser, usermod, su, whoami, pwd, hostname, cat, uname, lscpu, free, df, mkdir, nano, cp, touch, git

---

## Skills Learned
I learned how to create a user account and navigate directories confidently. I can now check system specs and keep files neat and organized. I also learned how to use Git to save work and write clear Markdown notes.
