# Automation Research

## Bash Script

A Bash script is a file that contains commands that Linux can run. The #!/bin/bash line tells the system to use Bash to run the script.

## Variables

Variables store values that can be used again in a script. For example, $BACKUP_DIR stores the backup folder name so we do not need to type it repeatedly.

## Cron Job

A Cron job is a task that runs automatically at a scheduled time in Linux. It is useful for automating tasks like backing up files without doing them manually.
