# System Baseline Report

## Host Resource Values
- **Total RAM available:** 1.9Gi
- **Total Storage capacity of root (`/`) file system:** 19G

## Importance of Disk Space Check
Checking disk space before a traffic surge is critical because growing user traffic creates more log files and temporary data; running out of storage can stop the server from writing necessary files, cause services to crash, or make the system unresponsive.
