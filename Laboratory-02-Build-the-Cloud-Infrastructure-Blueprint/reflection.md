# Reflection

I think Compute is the most important cloud infrastructure component because without processor and memory, no application or service can run at all. It is the core power behind everything in the cloud.

Linux supports cloud computing very well. It is free, stable, secure, and lightweight — perfect for servers. Most cloud platforms run on Linux because it works fast, can be fully controlled through commands, and supports all cloud tools.

Technical documentation is very important before deploying infrastructure. It keeps everyone organized, prevents mistakes, and makes future maintenance easier. Good records help the team understand exactly what was built and why.

I learned how to inspect a Linux server completely, identify infrastructure components, compare the three major cloud providers, and create a simple cloud architecture diagram. I also improved my skills in writing clear Markdown documentation.

My GitHub portfolio is much better now. It is organized properly by laboratory activity, all files are in correct folders, and screenshots are attached as proof. This activity gave me a strong foundation for understanding real cloud infrastructure.
