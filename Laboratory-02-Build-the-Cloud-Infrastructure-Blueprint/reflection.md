# Mission Reflection

I think Compute is the most important cloud infrastructure component because without processor and memory, no application or service can run at all. It is the core power behind everything in the cloud. Every task, program, and service depends on compute to process and work properly. No matter how much storage or network you have, nothing can function without compute power.

Linux supports cloud computing very well. It is free, stable, secure, and lightweight perfect for running servers. Most cloud platforms run on Linux because it works fast, can be fully controlled through commands, and supports almost all cloud tools. It is also open-source, so anyone can use and customize it without extra cost, which makes it ideal for cloud environments.

Technical documentation is very important before deploying infrastructure. It keeps everyone organized, prevents mistakes, and makes future maintenance easier. Good records help the team understand exactly what was built and why. If changes or updates are needed later, clear documentation saves time and avoids confusion among team members.

I learned how to inspect a Linux server completely using different commands, identify infrastructure components, compare the three major cloud providers, and design a simple cloud architecture diagram. I also improved my skills in writing clear Markdown documentation and using Git commands to save and share work properly.

My GitHub portfolio is much better now. It is organized properly by laboratory activity, all files are in correct folders, and screenshots are attached as proof. This activity gave me a strong foundation for understanding real cloud infrastructure and how to present work professionally.
