# Cloud Infrastructure Components

## Compute Resources
- *Purpose:* Runs programs and processes all tasks.
- *Importance in cloud computing:* It gives processing power. Cloud services cannot run or work without it.
- *Relation to KillerCoda:* This Linux environment uses CPU and memory to run all commands we executed.

## Storage Resources
- *Purpose:* Saves files, data, and the operating system permanently.
- *Importance in cloud computing:* Stores user data, backups, and applications. Keeps information safe.
- *Relation to KillerCoda:* All our lab files and folders are saved on this Linux server's disk.

## Networking Resources
- *Purpose:* Connects the server to the internet and other devices.
- *Importance in cloud computing:* Lets users access cloud servers remotely and connect services together.
- *Relation to KillerCoda:* The IP address lets us access this Linux terminal through a web browser.

## Operating System
- *Purpose:* Manages hardware and runs all programs and tools.
- *Importance in cloud computing:* It is the base layer. Every cloud server needs an operating system to function.
- *Relation to KillerCoda:* Ubuntu is the Linux system we used for all activities in this lab.
