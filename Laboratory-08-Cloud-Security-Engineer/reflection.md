# Mission Reflection

A host-based firewall protects a server by blocking unwanted connections and allowing only the traffic that is needed. Even if the network security is breached, the firewall can still protect the server by controlling which connections are allowed. This gives the server another layer of protection against unauthorized access.


Managing open network ports is important because attackers may use them to access the server. Closing ports that are not needed helps reduce security risks. By allowing only the necessary ports, the server becomes safer and has fewer ways for attackers to enter.


Leaving port 3306 for MySQL open to the public internet is dangerous because attackers may try to access the database and steal important information. They may also try to guess passwords or use security weaknesses to get in. To protect the data, database access should only be allowed for authorized users and trusted systems.


Completing this mission showed how easily a server can be attacked if it is not properly secured. It helped me understand that setting up a web application is not enough. We also need to configure a firewall, allow only the necessary ports, and check the server's security. These steps help reduce the risk of unwanted access.

Overall, these activities helped improve my knowledge and understanding of cloud computing.
