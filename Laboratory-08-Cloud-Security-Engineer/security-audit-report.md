# Security Audit Report

## Principle of Least Privilege (PoLP)

The Principle of Least Privilege means giving users only the permissions they need to do their tasks. It is important in cloud accounts because it helps prevent unauthorized access and reduces security risks.

## Attack Surface

The attack surface refers to all the possible ways an attacker can access or attack a virtual machine. Open ports, running services, and weak security settings can increase the attack surface.

## Default Deny Policy

A Default Deny Policy blocks all incoming traffic unless it is specifically allowed. It is safer because it prevents unauthorized connections without needing to identify and block every possible attacker.
