
# Reflection

This activity taught me more about how cloud storage can be used for large amounts of data. Object storage is useful for millions of photos because it is designed to store files such as pictures, videos, and backups. Instead of keeping everything on one traditional hard drive, files can be stored as objects inside a bucket. This makes it useful for applications where users upload many files.

Docker also made the MinIO setup easier. I did not have to install the storage server manually and configure every part of it. I was able to run one Docker command with the needed ports, credentials, and MinIO image. The container then provided the environment needed to run the storage server.

I learned that a bucket is a storage container where objects are kept. It helps organize files in an object storage system. For this activity, I created the client-photos bucket and uploaded a sample file to it. This helped me see how a cloud storage system works in practice.

Large companies can protect their stored data by making copies and keeping them in different servers or locations. They can also use backups and replication so that data can still be recovered when a server fails. These methods can help prevent important files from being permanently lost.

I also became more comfortable with basic Linux commands during this activity. I was able to run Docker commands and use docker ps to check the container. I still need more practice, but I understand the commands better now. This activity helped me become more familiar with using the command line for Docker and cloud-related tasks.
